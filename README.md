# bookchaowalit-ar-starter

Starter repository for the `bookchaowalit-ar` organization.

## Purpose

This repository is an intentionally thin baseline for AR/MR interfaces
and shared conventions under the Book Dev owner model. It contains no product
features yet.

## Repository boundary

- **Owner:** `bookchaowalit-ar`
- **Surface:** AR/MR
- **Book Dev category:** `book-apps/ar`
- **Default branch:** `main`
- **Status:** starter / skeleton

## CI

GitHub Actions runs the starter contract check on pushes and pull requests.
The workflow verifies that the required baseline files remain present.

## Local development

There is no runtime or dependency setup yet. Add implementation only when a
concrete AR/MR product is approved.
